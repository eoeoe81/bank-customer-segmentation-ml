# bank-customer-segmentation-ml
End-to-end machine learning project for customer segmentation using K-Means and Decision Tree

## Overview
An end-to-end Machine Learning project to segment bank customers based on their transaction behavior and build a classification model to predict customer groups.

## Tech Stack
**Language:** Python
**Libraries:** Pandas, Scikit-Learn, Matplotlib, Yellowbrick
**Algorithms:** K-Means Clustering, Decision Tree Classification

## Key Results
1. **Clustering:** Successfully segmented customers into 4 distinct clusters using K-Means (e.g., young active users, premium senior accounts).
2. **Classification:** Trained a Decision Tree model using the clustered data to classify new customer behaviors. 

## Project Structure
* `data_clustering.csv`: Cleaned dataset with cluster targets.
* `model_clustering.h5`: Trained K-Means model.
* `decision_tree_model.h5`: Trained Decision Tree model.
